# Описание модуля

В директории modules/vm добавлен модуль, создающий в облаке ресурс ВМ со всеми необходимыми компонентами (диск, сеть и т.п.).

## Параметры модуля

Параметры модуля определяются переменными Terraform:

- `vmname`: имя виртуальной машины (подставляется корневым модулем main.tf автоматически в зависимости от выбранного окружения)
- `cores`: количество ядер виртуальной машины
- `memory`: объем памятьи виртуальной машины
- `disk_size`: размер диска виртуальной машины
- `subnet_id`: идентификатор подсети
- `ssh_public_key`: публичный ключ для ssh (строка)

## Выходы модуля

- `vm_id`: идентификатор созданной ВМ
- `vm_name`: имя созданной ВМ
- `internal_ip`: внутренний IP-адрес
- `external_ip`: внешний IP-адрес
- `disk_id`: идентификатор созданного диска

## Запуск модуля

При локальной разработке желательно использовать отдельное рабочее пространство для каждой среды:

    terraform workspace new dev

Поскольку Subnet ID согласно требованиям задания должен быть параметром, он модулем не создается; ssh-ключ захардкодить тоже нельзя. Поэтому они передаются через переменные окружения:

    export TF_VAR_ssh_public_key="$(cat ~/.ssh/id_ed25519.pub)"
    export TF_VAR_subnet_id="..."

Выполнение модуля:

    terraform apply -var-file=envs/dev/terraform.tfvars

Откат внесенных изменений:

    terraform destroy -var-file=envs/dev/terraform.tfvars
