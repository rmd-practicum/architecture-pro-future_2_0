# Риски трансформации

## Архитектурные

- Расхождение данных в переходный период
  - Вероятность: высокая
  - Влияние: среднее
- Невыявленная скрытая логика в DWH, например, недокументированные хранимые процедуры; как следствие, искажение или потеря данных
  - Вероятность: средняя
  - Влияние: высокое
- Утечка медицинских данных в аналитику из-за ошибки при публикации событий в медицинском контуре
  - Вероятность: низкая
  - Влияние: высокое
- Непредвиденное изменение схем передаваемых сервисами событий
  - Вероятность: средняя
  - Влияние: среднее

## Организационные

- Нехватка компетенций команды при работе с новой архитектурой
  - Вероятность: выская
  - Влияние: высокое
- Сопротивление пользователей при переходе на новые инструменты аналитики
  - Вероятность: средняя
  - Влияние: среднее
- Регуляторные риски при переносе медицинских данных в облако
  - Вероятность: средняя
  - Влияние: высокое
- Повышенная нагрузка на сотрудников при миграции
  - Вероятность: высокая
  - Влияние: среднее

## Технологические

- Ограничения SQL Server 2008: старые версии протоколов, несовместимость с современными инструментами
  - Вероятность: высокая
  - Влияние: среднее
- Баги в opensource-компонентах: несовместимость версий компонентов, сбои, слабая поддержка
  - Вероятность: средняя
  - Влияние: среднее
- Отказ брокера событий, влекущий за собой простой всех процессов
  - Вероятность: низкая
  - Влияние: высокое
