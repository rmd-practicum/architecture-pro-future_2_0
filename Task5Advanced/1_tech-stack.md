## Практики и паттерны

| Технология | Статус | Обоснование |
|---|---|---|
| Event-drive architecture | Adopt | Обеспечивает гибкость, масштабируемость, обработку данных в near real time |
| Domain-driven design | Adopt | Разделяет систему на независимые домены |
| Infrastructure as code | Adopt | Упрощает развертывание, вопсроизводимость конфигураций, аудит |
| Data mesh | Trial | Позволяет разделить владение данными между ответственными командами |
| Data lakehouse | Trial | Гибкое, масштабируемое, дешевое хранение данных |
| DWH | Hold | Низкая производительность, затрудненное масштабирование |
| Бизнес-логика в DWH | Hold | Антипаттерн; увеличивает время разработки, усложняет поддержку |
| Централизованная сервисная шина | Hold | Ограничивает масштабирование, низкая гибкость |
| Ручное управление инфраструктурой | Hold | Высокая сложность и стоимость, низкая надежность |
